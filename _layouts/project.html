2D Project


Cat-acombs -
This is a top-down dungeon crawler, where you, the player, play as a cat exploring the dungeon, fighting off hordes of hoards od rats with your scarf. The game aims to help that cat escape the catacombs by solving puzzles, fighting rats and defeating an unholy boss.

cat-acombs has a designed to feel like a old churchs catacombs and having the boss feel like was summoned in church main hall, this game has alot of small feacture such as pot breaking and having the cats eye light up in dark places.

Experience -
The experience of creating my first 2D game using Unity was challenging at times, such as creating the AI that my rats used to path find to the player, but other times it was fun to get to know the processes of game creation, from tile mapping, sprite creation, and over level design/ worldbuilding.
Though this was the first time creating a 2D game using C# and Unity, I was still learning while creating, as it is still a demo, it will have bugs pointed out in the video.

Boardgame

Mecha –
This is a multiplayer, turn-based board game where movement is determined by rolling a D6 die. With up to four players, each takes turns racing around the board to collect pieces and parts for their mech. The main goal for players is to finish building their mech before others, This includes stealing and duelling to seize the chance to obtain the crucial parts of other players and make use of the perk cards to gove them tactical advantages.

Player can make use of a number of different spaces around the board to help the process in the game such as recyclers, shop and combat tiles.


{% include video id="UumIEOoHxgs" provider="youtube" %}


Experience -
The experience I had with building the board game is new, as I had no personal experience of creating them before, but going through the processes such as game-design documentation, user testing and getting my game finalised was a fun experience, as I could create my idea without having limitations in areas I wasn’t just as strong in yet. The experience of creating mecha was overall fun as it allowed me to use skills I already had, such as digital art for my game cards and hands-on work with game components.

3D Project

{% include figure image_path="/assets/images/Screenshot_2025-12-06_111340.png" alt="Game Jam screenshot" %}


This 3d project was the first-time using software such as ProBuilder. This project was on 3D graphics and level design to build a small work to get an understanding of how it was made, such as the use of texturing, Gray boxing and skyboxes.

The design I created is based on a medieval battle arena, showcasing elements like a viewing stand, barracks, weaponry, and castle structures. In the video below, there is a walkthrough of the map showing this off.

Experience -
Over the time, building and learning 3D graphics in Probuilder, I have become more confident with it. However, I still feel there is room to improve, such as small texture errors and a personal issue with being too perfectionistic about how objects were placed. Though I feel that over time, using this tool, I will eventually not run into these small errors. Eventually, I would like to learn how to produce textures myself, as this will allow me to have more control over the vision of these worlds I want to create.
